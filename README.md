# Pressure Test Log — marketing site

Static landing page for [Pressure Test Log](https://pressure-test-log.vercel.app/), a documentation tool for industrial pressure tests.

The page explains the product, shows screenshots of the live app, and includes an example PDF generated by that app. It does not change the app. Production is https://pressure-test-log-site.pages.dev. A merge to `main` deploys there automatically.

The GitHub repository is public: https://github.com/cruelreaver2-alt/pressure-test-log-site (`main`). Nothing private may be added: no secrets, no tokens, no `.env` files, no private app source, and no customer data.

## Preview locally

```bash
bash build.sh
python3 serve.py
```

Open http://127.0.0.1:4178

`build.sh` writes the Pages output to `dist/`. `serve.py` serves that directory. The page itself is plain HTML, CSS, and a small script.

## Cloudflare Pages

The Pages project `pressure-test-log-site` is connected to this Git repository. Merging to `main` deploys to production at https://pressure-test-log-site.pages.dev. Pull requests and other branches get preview deployments.

- Production URL: https://pressure-test-log-site.pages.dev
- Preview URL: `https://<branch>.pressure-test-log-site.pages.dev`
- Build command: `bash build.sh`
- Build output directory: `dist`
- Production branch: `main`

`main` is covered by the active ruleset **Protect Main**: a pull request is required, force-push is blocked, and deletion is blocked. No custom domain is connected yet. Rollback is from the Cloudflare Pages deployments list. Details are in `docs/cloudflare-pages.md`.

## Layout

- `index.html` — the page
- `css/site.css` — layout and type
- `js/site.js` — mobile menu only
- `assets/` — favicon, Open Graph image, screenshots, sample PDF
- `fonts/` — IBM Plex Sans, Latin, self-hosted
- `build.sh` — copies the public files into `dist/`
- `_headers`, `_redirects` — Cloudflare cache, security headers, and `/index.html` → `/`
- `docs/technical-report.md` — what was verified, and where
- `docs/cloudflare-pages.md` — GitHub, Pages, previews, rollback
- `docs/tracking.md` — Cloudflare Web Analytics is enabled; no advertising tag
