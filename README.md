# Pressure Test Log — marketing site

Static landing page for [Pressure Test Log](https://pressure-test-log.vercel.app/), a documentation tool for industrial pressure tests.

The page explains the product, shows screenshots of the live app, and includes an example PDF generated by that app. It does not change the app, and it is not deployed.

The GitHub repository is private: https://github.com/cruelreaver2-alt/pressure-test-log-site (`main`). Do not put secrets, private source, or customer data in it.

## Preview locally

```bash
bash build.sh
python3 serve.py
```

Open http://127.0.0.1:4178

`build.sh` writes the Pages output to `dist/`. `serve.py` serves that directory. The page itself is plain HTML, CSS, and a small script.

## Cloudflare Pages

Not connected, and not deployed. When a GitHub repository exists, the project settings are:

- Build command: `bash build.sh`
- Build output directory: `dist`
- Production branch: `main`, with automatic production deployments off until Kenneth approves

Details, branch protection, rollback, and the checklist are in `docs/cloudflare-pages.md`.

## Layout

- `index.html` — the page
- `css/site.css` — layout and type
- `js/site.js` — mobile menu only
- `assets/` — favicon, Open Graph image, screenshots, sample PDF
- `fonts/` — IBM Plex Sans, Latin, self-hosted
- `build.sh` — copies the public files into `dist/`
- `_headers`, `_redirects` — Cloudflare cache, security headers, and `/index.html` → `/`
- `docs/technical-report.md` — what was verified, and where
- `docs/cloudflare-pages.md` — GitHub, Pages, previews, rollback
- `docs/tracking.md` — where a tag would go; none is installed
